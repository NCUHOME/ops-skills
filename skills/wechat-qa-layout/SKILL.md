# 问答文案 → 公众号推文

一篇推文 = 一个 Markdown 文案文件 → `scripts/build.py` → 粘贴用 HTML + `预览.html`。

默认版式 `templates/jwdy.json` 取自已发布的「教务答疑直通车｜第三期：南昌大学本科新生秋季学期选课 Q&A」。样式数值和图片（公众号图床链接）都原样沿用，不要自创样式，也不要换图。

## 1. 开工前，一条消息问完

缺什么问什么，已经给了的不要再问：

- **文案来源**：docx / pdf / 文字，以及本篇用其中哪一部分。
- **视频**：文件路径。分不清哪个视频对应哪篇时，自己抽片头帧看标题（`ffmpeg -ss 1 -i 视频.mp4 -frames:v 1 片头.png`），再抽几帧确认讲的是哪些问题。
- **标题**：公众号标题栏用的完整标题，以及期数、篇名。片头上写了就照片头。
- **口径**：文案里前后矛盾的地方（同一件事两个数字、APP 与文件说法不同），列出来问以哪个为准，不要自己选。

## 2. 写文案文件

格式见 `references/FORMAT.md`。完整示例在 `examples/缓免测篇.md`，其余写法见 `examples/格式示例.md`。

- **问题、答案逐字照抄原文**。只允许下面这些排版处理：
  - 去掉数字与汉字之间的空格；
  - 长答案在分号处分段，列表按项换行；
  - 补句末标点；
  - 用 `**加粗**` 标出重点。

  其他任何改动（改写、合并、删减、补充）都要在交付时逐条列出，请用户确认。
- 按原文顺序（与视频一致）切成 3–5 个分区，分区标题写成「X篇｜a、b、c」。只有一个问题的分区直接写主题，例如「保健班学生免测」。
- 结尾 `## 温馨提示`：先写免责声明（有视频时用片尾那句），再写一两句祝福。祝福是新加的，要告诉用户。
- docx 转文字：`pandoc -t plain 文件.docx`，或用 python-docx。

## 3. 生成与自检

```bash
python3 <本 skill 目录>/scripts/build.py 文章1.md 文章2.md -o 输出目录
python3 <本 skill 目录>/scripts/build.py --check 文章.md     # 只查规范，不生成
```

- 终端打印的 ⚠️ 必须清零后再交付。
- 打开 `预览.html`。页面会在 360、375、390、430 四种手机宽度下自动自检：问题折行、分区标题撑出、内容溢出、两端对齐把字距撑大。结果显示在每篇上方。有浏览器工具就自己打开看，并逐屏截图检查。

## 4. 硬性要求

以下来自用户审稿，逐条遵守：

- **问题标题最多两行，绝不能出现三行、四行**（用户原话：“很丑，最多两行”）。
  - 每行不超过 12 字，这样 360px 宽的安卓手机也不折行。
  - 手动断行，断在逗号、问号或语义停顿处，例如 `### 测试过程中， / 感觉身体不适，怎么办？`。
  - 原问题两行放不下（大约超过 24 字）时，不要拆成三四行，也不要自己删字改写。把这些问题列给用户，由用户精简；用户给了写法再填进去。
- 分区标题不超过 15 字，否则窄屏会撑出画面。
- 两端对齐时，QQ 号、网址这类长串会把上一行撑出大空隙。生成器会自动让含长串的段落可以在串中间断行；网址再用反引号包住收紧字距，需要时用行末 `\` 让它单独成行。
- 视频位置放黄色虚线占位框，由用户在公众号编辑器里插入视频后删掉。不要尝试用代码嵌入视频。
- 图片只用公众号图床链接（`mmbiz.qpic.cn`），外链图片粘贴进编辑器会失败。公众号会过滤 `<style>`、class、`position` 和脚本，所以样式全部写成行内样式。

## 5. 交付时告诉用户

1. 文件：每篇一个 `.html`（正文代码），加一个 `预览.html`。
2. 视频文件与推文的对应关系，以及每篇的完整标题。
3. 你加的内容：分区标题、加粗、结尾祝福，以及做过哪些排版处理。
4. 需要用户确认的事项：文案矛盾、两行放不下的问题、任何改动过的句子。
5. 发布步骤，原样告诉用户：
   1. 打开预览页，点「复制排版」。
   2. 在公众号后台新建图文，把内容粘贴进正文。
   3. 在黄色虚线框处插入视频，再删掉虚线框。
   4. 点「复制标题」，填进标题栏。
   5. 用手机预览确认后，交给负责发布的人。

## 6. 其他情况

- **没有视频**：信息区不写「视频」，就不会出现视频提示条和占位框。
- **换单位、栏目或配色**：复制 `templates/jwdy.json`，改其中的 logo 图片链接、颜色和栏目名，生成时用 `--template 新文件.json` 指定。
- **照另一篇参考推文复刻全新版式**：见 `references/NEW-LAYOUT.md`，用 `scripts/outline.py` 拆解参考代码。
