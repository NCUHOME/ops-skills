# 文案文件写法

一篇推文对应一个 `.md` 文件，用 UTF-8 编码。生成的 `.html` 和文案文件同名。

```markdown
---
标题: 教务答疑直通车｜第六期：南昌大学《学生体质健康标准》Q&A（缓免测篇）
头图: 南昌大学 / 《学生体质健康标准》Q&A / （缓免测篇）
封面: 南昌大学 / 《学生体质健康标准》 / Q&A / （缓免测篇）
期数: 第六期
视频: 缓免测篇.mp4
---

## 缓免测申请篇｜流程、计分、测试

### 缓测、免测申请 / 提交流程是什么？
按照体测通知办理缓免测。具体办理流程看**体测通知附件1**。
**注：步道乐跑APP不接受线上提交缓免测申请。**

### 项目进行免测后， / 免测项目给予多少分？
免测的项目分数给予**及格分**，对应项目显示“免测”。

## 最后再次划重点
需要缓测、免测的同学，请按体测通知附件1的流程办理，**步道乐跑APP不接受线上提交申请**。……
免测项目按**及格分**计，未免测的项目仍要正常预约测试；……
具体安排以学校发布的体测通知为准，祝愿每位同学都能顺利完成体质测试🏃
```

## 开头信息区

写在两行 `---` 之间。冒号用中文或英文都可以。

| 键 | 必填 | 说明 |
|---|---|---|
| 标题 | ✅ | 公众号标题栏用的完整标题。预览页的「复制标题」复制的就是它 |
| 头图 | ✅ | 头图上的大标题，最多三行，行与行之间用 ` / ` 隔开。和视频片头、往期封面用同一种写法；字号会自动缩放 |
| 封面 | | 封面上的标题，多行用 ` / ` 隔开，例如 `南昌大学 / 《学生体质健康标准》 / Q&A / （体质测试篇）`。不写就用「头图」 |
| 模板 | | 模板库里的模板名（如 `jwdy`），或模板文件夹路径（相对本 .md，如 `推文模板/ncuhome-blue`）。不写用 `jwdy`；生成时 `--template` 会覆盖这里 |
| 期数 | | 显示在头图下方的小字里，例如「- 教务答疑直通车 第六期 -」。不写就只显示栏目名 |
| 栏目 | | 不写就用模板里的栏目名（教务答疑直通车） |
| 视频 | | 视频文件路径（相对于本 .md）或文件名。写了才会出现「点击下方观看动画短片」提示条和视频占位框。文件存在且电脑装了 ffmpeg 时，会自动读取时长并截一帧作为预览页里的视频封面 |
| 时长 | | 例如 `03:57`，读不到视频文件时手动填 |
| 封面帧 | | 预览页里视频封面用的图片。不写就自动截取 |
| 视频提示 | | 视频上方的提示文字，默认「（点击下方观看动画短片）」 |

## 正文

| 写法 | 效果 |
|---|---|
| `## 分区标题` | 一条绿色分区标题，下面跟一张白色卡片 |
| `### 第一行 / 第二行` | 一个问题：黄色圆形编号（每个分区从 01 开始）加虚线问题框。` / ` 两边要留空格。**最多两行，每行不超过 12 字** |
| 问题下面的每一行 | 答案的一段，首行缩进 |
| 行末加 `\` | 下一行接在同一段里换行（不缩进），适合写列表和网址 |
| `**文字**` | 加粗 |
| `` `文字` `` | 收紧字距，用于网址、长串数字，或差一两个字就放不下的短行 |
| 分区标题下面、第一个问题之前的行 | 卡片里的普通段落，例如联系方式列表 |
| `## 最后再次划重点` 下面的每一行 | 结尾的总结框，每行一段，最前面自动加上「💡最后再次划重点：」。推荐用它做结尾 |
| `## 温馨提示` 下面的每一行 | 结尾居中的小字，最前面会自动加上「💡温馨提示：」 |
| `<!-- 注释 -->` | 不会输出，可以用来记录原文和备注 |

## 断行与字数

360px 宽的手机上，正文宽 328px。问题框里 16px 的字加 1px 字距，一行大约放 12 个字。所以：

- 问题每行不超过 12 字，最多两行，断在逗号、问号或语义停顿处；
- 分区标题不超过 15 字；
- 运行 `build.py --check` 会列出超出的地方。字数按汉字计 1、半角字母和数字计 0.72 估算。

以上是默认模板的限制，别的模板以它 `template.json` 里的 `limits` 为准。
