# 照一篇参考推文复刻新版式

默认版式就是这样从「教务答疑直通车」第三期复刻出来的。换一篇参考推文时，按同样的步骤做。

## 1. 拿到参考推文的代码

- **已发布的文章**：用电脑浏览器打开文章链接，打开开发者工具，选中正文节点 `#js_content`，右键 Copy → Copy outerHTML，存成 `参考.html`。
- **草稿**：在公众号后台编辑器里，用同样的方法复制正文节点。也可以用插件导出“文章代码”。

## 2. 拆结构

```bash
python3 scripts/outline.py 参考.html            # 缩进大纲：标签、关键样式、文字、图片编号
python3 scripts/outline.py 参考.html --images   # 全部图片链接，按出现顺序去重
```

## 3. 认出构件

常见的构件有：头图、提示条、分区标题、卡片、问题行、答案段、结尾。同一种构件出现多次时，对比几处的样式，分清哪些是固定的、哪些会变（文字、编号、上边距）。

## 4. 抄样式时的坑

- **图片宽度**：导出的代码是浏览器渲染后的结果，图片宽度被写死成像素（例如 `width: 308px !important`）。真正的样式在 `data-original-style` 里，通常是 `width: 100%`，要用这个。`outline.py` 已经替你取了这一项。
- **编辑器痕迹**：去掉 `visibility: visible`、`leaf=""`、`nodeleaf`、`data-*` 等属性。
- **视频**：视频是一大段 `<span class="video_iframe">` 播放器代码，换成占位框，由用户在编辑器里重新插入。
- **头图**：常见做法是用 `display: grid` 叠层。每一层都写 `grid-row-start: 1; grid-column-start: 1`，用 `margin-left` 和 `margin-top` 的百分比定位（注意 `margin-top` 的百分比是相对**宽度**算的），文字放在 SVG 的 `foreignObject` 里。保留原结构，只换文字。
- **被过滤的写法**：公众号会过滤 `<style>`、class 选择器、`position`、脚本和外链图片。样式一律写成行内样式，图片用公众号图床链接（`mmbiz.qpic.cn`）。
- **自己的新图片**：先在公众号后台上传到素材库或正文里，再复制它的图片地址。

## 5. 写进代码

- **只换颜色、图片、栏目名**：复制 `templates/jwdy.json` 改一份，生成时用 `--template` 指定。
- **结构不一样**：在 `scripts/build.py` 里照现有写法新增或修改构件函数。构件函数用 `E("section", 行内样式, 子元素…)` 拼出带行内样式的 section；预览自检要定位的构件加上 `attrs=chk(pv, "q" | "title" | "ans")`。

## 6. 重新算行宽限制

手机正文宽度 = 屏幕宽度 − 32px，360px 宽的手机是 328px。按新版式的卡片宽度、内边距和字号，算出问题框一行能放几个字：

> 可放字数 = 可用宽度 ÷（字号 + 字距）

把结果更新到版式文件的 `limits` 里。

## 7. 验证

用 `预览.html` 的自检看 360、375、390、430 四种宽度，并和参考推文逐块对比截图。
